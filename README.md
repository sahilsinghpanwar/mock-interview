# Mock Interview

## What it does
An AI-powered mock interview platform designed to help candidates practice interview questions, receive real-time feedback, and prepare effectively for technical and behavioral interviews.

## Tech Stack
React | Next.js | Node.js | Firebase | Tailwind CSS

## Live Demo
[https://mock-interview-azure-rho.vercel.app](https://mock-interview-azure-rho.vercel.app)

## How to run
```bash
npm install
npm run dev
```
