## 🚀 Quick Start (5 Steps)

### Step 1: Create VAPI Account
- Visit https://vapi.ai
- Sign up with email/Google/GitHub
- Add billing method
- Get API keys

### Step 2: Create Voice Assistant
- Go to Assistants → Create
- Select voice: "Alloy" or "Nova"
- Model: GPT-4 Turbo
- Copy system prompt from VAPI_SETUP_GUIDE.md
- Save and get Assistant ID

### Step 3: Setup Environment
```bash
# Add to .env.local
NEXT_PUBLIC_VAPI_PUBLIC_KEY="pk_..."
VAPI_API_KEY="sk_..."
NEXT_PUBLIC_VAPI_ASSISTANT_ID="assistant_..."
NEXT_PUBLIC_BASE_URL="http://localhost:3000"
```

### Step 4: Configure Webhooks
- In VAPI Assistant settings
- Enable: call-ended, recording-available
- Set webhook URL: `http://localhost:3000/api/interview/complete`
- Save

### Step 5: Test Locally
- Run: `npm run dev`
- Go to http://localhost:3000
- Start interview
- Allow microphone
- VAPI calls you!

## 🎯 What Happens When Everything Works

1. **User signs in** → Authenticated with Firebase
2. **Selects interview** → Fills out field & level
3. **Clicks "Start"** → Questions generated by Gemini
4. **Initiates call** → VAPI connects via voice
5. **Agent asks questions** → From system prompt
6. **User responds** → Audio recorded & transcribed
7. **Interview ends** → Webhook sends transcript
8. **Gemini evaluates** → Scores & feedback generated
9. **Results shown** → User sees score & feedback

**Total time: 25-35 minutes per interview**

## 💻 Code Architecture

Your app uses these technologies:

```
Frontend (React/Next.js)
├─ AuthForm (Sign in/up)
├─ InterviewSetupForm (Field + Level)
├─ VoiceInterviewPanel (Mic interface)
└─ FeedbackPage (Results)

Backend (Next.js API Routes)
├─ /api/interview/create (Gemini generates questions)
├─ /api/interview/start-call (VAPI initiates call)
└─ /api/interview/complete (Webhook from VAPI)

Services
├─ gemini.service.ts (Question generation & evaluation)
├─ vapi.service.ts (Voice call management)
└─ interview-session.service.ts (Session data)

External APIs
├─ Firebase (Auth + Database)
├─ Gemini (AI for questions & feedback)
└─ VAPI (Voice calls & recording)
```

## 💰 Cost Breakdown

### VAPI Pricing:
- Inbound calls: $0.10/minute
- Outbound calls: $0.10/minute
- Recording storage: $0.01/minute/month

### Example Costs:
```
For 100 interviews/month:
- Interview time: 100 × 25 min = 2,500 min
- Call cost: 2,500 × $0.10 = $250
- Storage: 2,500 × $0.01 = $25
- Total: ~$275/month

For 1,000 interviews/month:
- Call cost: 25,000 × $0.10 = $2,500
- Storage: 25,000 × $0.01 = $250
- Total: ~$2,750/month
```

### Ways to Optimize:
- Set max call duration (35 min)
- Archive old recordings
- Monitor usage daily
- Set billing alerts
- Use cheaper voice options

## 🚀 Production Deployment

### On Vercel:

1. **Add Environment Variables:**
   - Dashboard → Settings → Environment Variables
   - Add all keys from .env.local
   - Set NEXT_PUBLIC_BASE_URL to your domain

2. **Update Webhook URL:**
   - VAPI Dashboard → Assistant Settings
   - Change webhook to: `https://yourdomain.com/api/interview/complete`

3. **Configure Authorized Domains:**
   - VAPI Settings → Authorized Domains
   - Add your production domain

4. **Test:**
   - Go to your production URL
   - Complete full interview
   - Verify everything works

5. **Monitor:**
   - Check VAPI call logs
   - Monitor database size
   - Track costs daily
   - Collect user feedback
